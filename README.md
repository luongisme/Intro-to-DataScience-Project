# IT135IU Data Science Project

## Course
IT135IU – Introduction to Data Science

## Project

The project decision question and dataset will be selected later.

## Repository Structure

- `data/raw/` – original raw datasets
- `data/interim/` – intermediate datasets
- `data/processed/` – cleaned and analysis-ready datasets
- `notebooks/` – Jupyter notebooks for the Data Science workflow
- `src/` – reusable Python code
- `reports/figures/` – generated figures
- `reports/tables/` – generated tables
- `docs/` – project documentation
- `presentation/` – presentation materials

## Workflow

Decision Question
→ Data
→ Cleaning
→ Analysis
→ Visualisation
→ Findings
→ Recommendation
