# Decision Question

## Stakeholder
Who will act on the result?

## Decision
What exactly must they decide?

## Options
What alternatives are available?

## Success Criteria
How will one option be judged better than another?

## Information Needed
What information is necessary to make the decision?

## Required Data
What variables and granularity are required?

## Feasibility Check
- Dataset available?
- >= 50,000 rows if tabular?
- Required variables available?
- Correct granularity?
- Relevant time coverage?
- Relevant geographic coverage?
- Download allowed?
- Academic/research use allowed?
- Privacy concerns?
- Merge keys available if multiple datasets?
