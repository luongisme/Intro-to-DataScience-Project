# Contributing Guidelines

## Branches
- `main`
- `feature/data-engineering`
- `feature/analysis`
- `feature/visualisation`
- `feature/documentation`

## Collaboration Rules
1. Do not work directly on `main` for substantial changes.
2. Pull latest changes before beginning work.
3. Use meaningful commits.
4. Keep commits focused.
5. Request at least one teammate review before merging important changes.
6. Avoid multiple members editing the same Jupyter notebook simultaneously.
7. Do not commit passwords, API keys, or confidential data.

## Recommended Commit Message Examples
- `data: add raw dataset loading`
- `clean: handle duplicate records`
- `analysis: add group comparison`
- `viz: add delay-rate figure`
- `docs: update data source information`
- `fix: correct merge validation`
